FAQ

Good to know before installing.

Gut zu wissen vor der Installation.

Do I need Claude, ChatGPT, and OpenCode Go?Brauche ich Claude, ChatGPT und OpenCode Go?

No. Connect Claude, ChatGPT, or both. OpenCode Go monitoring is optional and off by default.

Nein. Verbinde Claude, ChatGPT oder beide. OpenCode Go ist optional und standardmäßig ausgeschaltet.

Does Token Monitor reuse browser cookies?Verwendet Token Monitor meine Browser-Cookies?

No. Every provider uses its own persistent WebKit session inside the app.

Nein. Jeder Provider nutzt eine eigene persistente WebKit-Session in der App.

Can I switch provider accounts?Kann ich den Provider-Account wechseln?

Yes. Reconnect preserves the existing provider session. Switch account and Disconnect clear only the selected provider session; Google sign-in then shows the account chooser.

Ja. Neu verbinden behält die bestehende Provider-Sitzung. Account wechseln und Verbindung trennen löschen nur die ausgewählte Provider-Sitzung; bei Google Sign-in erscheint anschließend die Account-Auswahl.

How does Token Monitor update?Wie wird Token Monitor aktualisiert?

Manual checks are available in Settings. From version 1.0.22, automatic update checks are off by default and can be enabled there.

Manuelle Prüfungen sind in den Settings verfügbar. Ab Version 1.0.22 sind automatische Update-Prüfungen standardmäßig aus und können dort aktiviert werden.

Is this an official Anthropic or OpenAI app?Ist das eine offizielle App von Anthropic oder OpenAI?

No. Token Monitor is an independent open-source utility and is not affiliated with Anthropic, OpenAI, or Apple.

Nein. Token Monitor ist ein unabhängiges Open-Source-Werkzeug und nicht mit Anthropic, OpenAI oder Apple verbunden.

Why is Token Monitor missing from Login Items?Warum fehlt Token Monitor bei den Anmeldeobjekten?

Launch at login uses Apple's ServiceManagement API, which expects a code-signed app. Move TokenMonitor.app to Applications, open it once, and enable Launch at login in Settings.

Launch at login nutzt Apples ServiceManagement-API, die eine signierte App erwartet. Verschiebe TokenMonitor.app nach Applications, öffne sie einmal und aktiviere Launch at login in den Settings.
